NETWORK MATURITY PROGRAM

Help ZORYQ move beyond a single-node testnet.

The current public network is a centralized Anvil-based execution environment. ZORYQ is recruiting technically capable operators to validate the next architecture and eventually operate independent nodes in a multi-operator devnet.

Current state

0 independent consensus validators.

One public gateway. No verified fault tolerance or automatic regional failover.

Target

3 independently operated nodes.

Deterministic head agreement, restart/catch-up tests, outage tests and documented recovery.

Claim discipline

Node registration or heartbeat does not make the current chain decentralized.

Decentralization claims remain blocked until multi-validator consensus is implemented and tested.

Operator requirements

Linux or container experience · EVM node familiarity · persistent storage · ability to expose health telemetry · willingness to participate in restart, catch-up, partition and recovery drills.

Execution phases

Phase 1 — architecture reproducibility: independent operators reproduce the documented chain configuration locally and report gaps.

Phase 2 — multi-node devnet: minimum three operators run the selected consensus architecture with independent keys and persistent data.

Phase 3 — fault testing: node restart, catch-up, one-node outage, network partition and recovery tests.

Phase 4 — public testnet migration: only after evidence exists and rollback procedures are proven.
