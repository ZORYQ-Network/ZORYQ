FIRST EXTERNAL BUILDERS

Deploy something real on ZORYQ.

The goal is simple: move ZORYQ from internal protocol activity to independently built applications. Build a small EVM app, verify it on-chain, and become part of the public ecosystem record.

Start in under 5 minutesGet test ZQDeveloper portal

What counts

A contract or dApp deployed by an independent builder, with a verifiable transaction and source/demo that others can inspect.

Small is fine. Real and reproducible beats large and unfinished.

Good starter ideas

Agent action demo, escrow, simple NFT utility, on-chain guestbook, DeFi composition, analytics widget, identity experiment or Project Registry integration.

What ZORYQ provides

Public RPC, faucet, Explorer, Foundry/viem/ethers examples, native DEX, Stake, Lending, Project Registry and machine-readable agent context.

External builder path

Add ZORYQ EVM Testnet — Chain ID 5919065.
Claim test ZQ from the public faucet.
Deploy with Foundry, viem, ethers or another standard EVM tool.
Open the receipt and contract in Explorer.
Publish a minimal README or demo and share the transaction/contract address with @ZORIQNetwork.
For project-level experiments, anchor a project identity in the live Project Registry.

This is a testnet builder program, not an investment or token promise. ZQ and zUSD have no monetary value.

Public target

ZORYQ is explicitly targeting its first 10 independent developers and first external dApps. The public metrics page will remain evidence-first; internal/self-interactions are not represented as external adoption.
