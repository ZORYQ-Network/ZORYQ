Methodology

Observed TPS = transactions included in the sampled block interval divided by elapsed on-chain time. Peak observed TPS = highest single sampled block transaction count divided by its interval. Ggas/s = sampled gas used divided by elapsed time and 1,000,000,000. These values describe current observed load, not maximum capacity. Observed continuity means no sampled inter-block gap exceeded 2.5× the sample median; it is not presented as audited 24/7 uptime.

CPU is currently a timestamped Railway infrastructure snapshot, not yet a public live container counter. It will become fully live once native CPU telemetry is exported.

Stress-test ladder

Controlled sequence: RPC read-only baseline → 1M → 10M → 100M transactions. Each result must publish hardware/container limits, concurrency, transaction mix, duration, accepted/rejected requests, p50/p95/p99 latency, sustained TPS, peak TPS, block time, gas throughput, RAM peak, CPU peak and state growth.
