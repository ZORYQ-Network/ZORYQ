THE TECHNICAL THESIS

Make onchain software legible to humans, agents and capital.

ZORYQ is an experimental EVM testnet built around one thesis: the next generation of onchain products will be built by humans and software agents together. The chain should expose not only execution, but machine-readable intent, project identity, verifiable activity and builder reputation.

01 · EXECUTION

Standard EVM

Solidity, Foundry, viem, ethers and ordinary wallets. ZORYQ does not ask developers to relearn the execution layer before experimenting.

02 · INTENT

Agent-readable actions

Machine-readable context and action manifests can describe targets, methods, value, expected output and signing boundaries before execution.

03 · IDENTITY

Projects onchain

The live Project Registry gives builder-owned projects a canonical slug, manifest pointer and content hash instead of relying only on offchain profiles.

04 · EVIDENCE

Proof, not vanity

Receipts, bytecode, registry records and protocol events are the primitive. Internal Treasury activity is not presented as external adoption.

05 · INTELLIGENCE

Builder graph

Project Intelligence and Builder Reputation are designed to turn verifiable contribution and usage into a machine-readable builder layer.

06 · COMPOSABILITY

Primitives already live

DEX, lending, staking and zUSD give developers useful contracts to compose with on day one rather than an empty test chain.

THE PRODUCT LOOP

One system. One coherent path.

Discover → Fund → Build → Simulate → Sign → Verify → Register → Measure → Build reputation.

Every developer surface exists to shorten this loop. Every intelligence surface exists to make its output verifiable. Every protocol primitive exists to give builders something useful to compose.

What is real today

Public Chain ID 5919065 and RPC; live DEX, Lending, Stake, zUSD and Project Registry; public faucet and explorer; agent schemas; Devkit; five-minute build path; network maturity disclosure. The network is currently a centralized public testnet — not mainnet and not a decentralized validator network.
