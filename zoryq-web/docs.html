Build on ZORYQ

ZORYQ EVM Testnet is an Ethereum-compatible execution environment for testing smart contracts, dApps, fungible tokens and NFTs using familiar EVM tooling. Testnet ZQ has no financial value.

Add ZORYQ to an EVM wallet

Use the button below in MetaMask-compatible wallets, or enter the network details above manually.

JavaScript

await window.ethereum.request({
  method: 'wallet_addEthereumChain',
  params: [{
    chainId: '0x5a5159',
    chainName: 'ZORYQ EVM Testnet',
    nativeCurrency: { name: 'ZORYQ', symbol: 'ZQ', decimals: 18 },
    rpcUrls: ['https://zoryq-evm-node-production.up.railway.app/rpc'],
    blockExplorerUrls: ['https://zoryq-testnet.vercel.app/explorer.html']
  }]
})

Faucet

The Testnet faucet distributes 100 test ZQ per address per 24 hours. Funds are for gas and contract testing only.

POST https://zoryq-evm-node-production.up.railway.app/faucet
Content-Type: application/json

{ "address": "0xYourWallet" }

JSON-RPC

The public gateway supports standard Ethereum JSON-RPC and blocks administrative namespaces such as anvil_*, hardhat_*, evm_* and debug_*.

Chain ID

curl -X POST https://zoryq-evm-node-production.up.railway.app/rpc \
  -H 'content-type: application/json' \
  --data '{"jsonrpc":"2.0","id":1,"method":"eth_chainId","params":[]}'

Common methods

eth_chainId · eth_blockNumber · eth_getBalance · eth_getCode · eth_call · eth_sendRawTransaction · eth_getTransactionReceipt · eth_getLogs

Smart contracts

ZORYQ supports standard Solidity bytecode and contract creation. Connect Remix, Foundry or Hardhat to the RPC and deploy as you would on another EVM network.

Foundry

export ZORYQ_RPC=https://zoryq-evm-node-production.up.railway.app/rpc
forge create src/MyContract.sol:MyContract --rpc-url $ZORYQ_RPC --private-key $TESTNET_PRIVATE_KEY

Use a dedicated disposable Testnet key. Never use a production, treasury or Mainnet private key.

ERC-20 tokens

Deploy standard OpenZeppelin ERC-20 contracts on ZORYQ. The Testnet validates contract creation, balance queries, transfers, receipts and logs.

contract DemoToken is ERC20 {
  constructor() ERC20("Demo Token", "DEMO") {
    _mint(msg.sender, 1_000_000 ether);
  }
}

ERC-721 / NFTs

Mint ERC-721 NFTs, query ownerOf, transfer assets and inspect emitted Transfer logs through the Explorer or RPC.

contract DemoNFT is ERC721 {
  constructor() ERC721("Demo NFT", "DNFT") {}
  function mint(address to, uint256 id) external { _mint(to, id); }
}

Tooling

Compatible workflows include MetaMask, Rabby, OKX Wallet, Remix, ethers, viem, Foundry and Hardhat. Configure each tool with the ZORYQ RPC and Chain ID 5919065.

Security model

ZORYQ EVM Testnet is a centralized public testing environment, not a production Mainnet consensus network. Test funds have no value. Administrative RPC methods are intentionally blocked by the public gateway. Secrets belong only in hosting-provider secret storage; mnemonics, seeds and private keys must never be committed to source control.
