2 · Create a Foundry project
forge init hello-zoryq
cd hello-zoryq
3 · Add a contract
// src/HelloZoryq.sol
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;

contract HelloZoryq {
  string public message = "Hello ZORYQ";
  address public immutable builder = msg.sender;

  event MessageChanged(address indexed builder, string next);

  function setMessage(string calldata next) external {
    message = next;
    emit MessageChanged(msg.sender, next);
  }
}
4 · Build and deploy
forge build
forge create src/HelloZoryq.sol:HelloZoryq \
  --rpc-url https://zoryq-evm-node-live-production.up.railway.app/rpc \
  --private-key "$ZORYQ_TESTNET_PRIVATE_KEY"

Use a disposable testnet wallet. Never commit private keys or seed phrases. Wallet-native or encrypted signing is preferable whenever available.

5 · Prove it exists

Open the deployed address in the Explorer:

https://zoryq-evm-node-live-production.up.railway.app/address/<CONTRACT_ADDRESS>

If the deployment receipt and bytecode are visible, you have a verifiable ZORYQ contract.
