2 · Create a Foundry project
forge init hello-zoryq
cd hello-zoryq
3 · Add a contract
// src/HelloZoryq.sol
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;
contract HelloZoryq {
  string public message = "Hello ZORYQ";
  function setMessage(string calldata next) external { message = next; }
}
4 · Build and deploy
forge build
forge create src/HelloZoryq.sol:HelloZoryq \
  --rpc-url https://zoryq-evm-node-live-production.up.railway.app/rpc \
  --private-key "$DEPLOYER_PRIVATE_KEY"

Never commit a private key. Prefer wallet-native signing, a hardware wallet or encrypted local key management where possible.

5 · Verify

Open your deployed address at:

https://zoryq-evm-node-live-production.up.railway.app/address/<CONTRACT_ADDRESS>

If bytecode and your deployment receipt are visible, you are live on ZORYQ Testnet.
