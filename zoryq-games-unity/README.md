# ZORYQ Games / Unity

This project is the production gameplay layer for ZORYQ Play. The React Native wallet remains the account/wallet hub; game runtime is isolated from seed phrases, private keys and real wallet balances.

## First vertical slice: Rush City

Implemented source systems:
- responsive three-lane runner movement with swipe controls
- jump, slide and wall-run state
- progressive speed/difficulty director
- procedural/recycled track segments
- obstacles, ZQ collectibles and combo multiplier
- procedural neon city dressing
- chase pressure system
- dynamic follow camera/FOV
- ZORYQ Play session result bridge for Android
- editor scene builder (`ZORYQ > Rush City > Build Vertical Slice Scene`)

## Open in Unity

Open this folder as a Unity project. Then run the editor command:

`ZORYQ > Rush City > Build Vertical Slice Scene`

It creates `Assets/ZORYQ/RushCity/Scenes/RushCityVerticalSlice.unity`, wires the runtime systems and adds the scene to Build Settings.

## Production rule

The procedural meshes/materials generated by the scene builder are engineering stand-ins used to validate movement, camera, route generation and performance. They are NOT the final art target. Production character, animation, environment, VFX and audio assets must replace them before a release is described as commercial-quality.

## Wallet security boundary

The game reports only a signed/validated session payload shape (session id, score, distance, collected in-game ZQ, duration). The Unity runtime does not receive wallet private keys, seed phrases or spend permissions. Server-authoritative reward settlement is the production target.
