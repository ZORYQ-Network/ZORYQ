# ZORYQ

ZORYQ is the official product and brand name for this mobile Web3 wallet project.

## Brand migration
- Previous working name: KYVO / Kyvo
- Official name: ZORYQ
- Product name: ZORYQ Wallet
- Ecosystem naming: ZORYQ Pay, ZORYQ Swap, ZORYQ Earn, ZORYQ Card, ZORYQ Network, ZORYQ Labs

## Identity
Keep the existing visual identity direction already defined for the project: premium, clean, modern, international, Web3-oriented, with the same visual system previously designed for KYVO. Only the brand name/wordmark should change to ZORYQ unless a specific asset is intentionally redesigned.

## Naming rules
Use `ZORYQ` in user-facing branding and `zoryq` in package IDs, slugs, folders, configuration keys, and technical identifiers where lowercase is required.

Do not introduce new references to KYVO, Kyvo, KYVRA, Kyvra, KYVORA, or Kyvora.
