# ZORYQ

ZORYQ is the official product and brand name for this Web3 project and ecosystem.

## Brand system
- Official name: ZORYQ
- Network name: ZORYQ Network
- Product name: ZORYQ Wallet
- Ecosystem naming: ZORYQ Pay, ZORYQ Swap, ZORYQ Earn, ZORYQ Card, ZORYQ Social, ZORYQ Developer, ZORYQ Metrics and ZORYQ Labs

## Identity
Keep the visual identity premium, clean, modern, international and Web3-oriented. The core visual direction uses a dark/black base with vibrant cyan, electric blue, violet and magenta accents, strong contrast and restrained neon effects.

## Naming rules
Use `ZORYQ` in user-facing branding and `zoryq` in package IDs, slugs, folders, configuration keys and technical identifiers where lowercase is required.

## Brand protection
All current documentation, workflows, artifacts, interfaces and public-facing assets must use the ZORYQ identity consistently. Previous working names must not be reintroduced into current repository content.
