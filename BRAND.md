# ZORYQ Brand

ZORYQ is the single canonical name for the project, product, network and ecosystem.

## Canonical naming

- Brand: `ZORYQ`
- Technical prefix: `zoryq`
- Network: `ZORYQ EVM Testnet`
- Native testnet symbol: `ZQ`
- Wallet: `ZORYQ Wallet`
- Social: `ZORYQ Social`
- Developer platform: `ZORYQ Developer`
- Protocol and ecosystem naming: `ZORYQ Network`, `ZORYQ Swap`, `ZORYQ Earn`, `ZORYQ Labs`

## Naming rules

Use `ZORYQ` in all user-facing text, documentation, titles, metadata and product surfaces.

Use `zoryq` only where lowercase technical identifiers are appropriate, including package names, slugs, folders, routes, configuration keys and process labels.

Do not introduce alternative spellings, former working names or parallel brand identities anywhere in the current codebase.

## Repository standard

New files, workflows, branches, routes and documentation should use descriptive ZORYQ-first naming. Avoid duplicate implementations, temporary archives and obsolete compatibility aliases unless a migration requirement is explicitly documented.

## Visual direction

The ZORYQ identity should remain premium, clean, modern, international and Web3-oriented, with a restrained interface, dark/light contrast and selective vibrant neon accents.
