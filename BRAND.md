# ZORYQ

ZORYQ is the official product and ecosystem brand name. Always write the public-facing name as **ZORYQ** — with **Y**.

## Brand migration
- Previous working names: KYVO / Kyvo and other internal experiments
- Official name: ZORYQ
- Product family: ZORYQ Wallet, ZORYQ Social, ZORYQ Swap, ZORYQ Earn, ZORYQ Network, ZORYQ Labs, ZORYQ Explorer, ZORYQ Docs

## Visual identity
ZORYQ uses one unified visual language across Web, APK/mobile, Explorer, Docs, Social, Wallet, Swap, Node surfaces, dashboards and launch tools.

Direction: **premium, vivid, technological, international and professional**. The interface is dark-first with glass surfaces, tone-on-tone gradients, controlled neon glow, strong hierarchy and high readability. Saturated color is used intentionally for emphasis, status and identity rather than as uncontrolled decoration.

### UI rules
1. Near-black backgrounds and elevated translucent/glass panels are the base.
2. Use violet, magenta, cyan and lime for product identity and interaction emphasis.
3. Use green for verified/healthy/success states, amber for warnings and orange-red for destructive/error states.
4. Cards, inputs and navigation use subtle borders and soft depth; neon glow must remain controlled.
5. Use rounded geometry consistently: 18px standard radius and 26px for large hero surfaces.
6. Motion must be restrained, purposeful and respect `prefers-reduced-motion`.
7. Web and APK must look like two responsive clients of the same product, not separate brands.

## Naming rules
Use `ZORYQ` in all user-facing branding and `zoryq` in package IDs, slugs, folders, configuration keys and technical identifiers where lowercase is required.

Do not introduce new user-facing references to ZORIQ, KYVO, Kyvo, KYVRA, Kyvra, KYVORA or Kyvora. Legacy technical filenames may remain temporarily only when renaming them would break automation; their visible content must use ZORYQ.
