# ZORYQ Benchmarks

This directory is reserved for **reproducible benchmark code, configurations and raw/result artifacts**.

A benchmark is not accepted as evidence when only a headline number is committed.

## Suggested organization

Create subdirectories only when real benchmarks exist:

- `micro/`
- `macro/`
- `execution/`
- `state/`
- `consensus/`
- `network/`
- `contention/`
- `recovery/`

Each benchmark should include a README or metadata file describing the exact environment, commit, workload, configuration and limitations.

See the root `BENCHMARKS.md` for the mandatory methodology.
