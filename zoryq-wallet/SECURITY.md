# ZORYQ Wallet Security Notes

- Never request a recovery phrase through support, forms, social media, email or chat.
- Never transmit mnemonic/private key material to ZORYQ servers.
- Never log mnemonic/private key material.
- Never add analytics events containing wallet secrets.
- Treat clipboard contents as untrusted and verify addresses before signing.
- Mainnet is disabled until independent review and real-device testing are complete.
