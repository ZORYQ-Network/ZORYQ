# ZORYQ Mobile Node

Implementation branch for the ZORYQ Mobile Witness Node and official APK download surface.

Goals:
- Android-friendly witness/light-node participation
- verify chain identity and block progress from multiple RPC peers
- conservative battery/network behavior
- visible contribution metrics without claiming validator status
- official APK download entry point on the ZORYQ website

This file is temporary project scaffolding and will be refined as implementation lands.
