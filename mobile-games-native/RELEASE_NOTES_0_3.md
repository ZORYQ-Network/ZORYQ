# ZORYQ Games Native 0.3 alpha

This candidate brings the three initial native game vertical slices into one Games Hub:

- Rush: runner loop, obstacles, jump/slide, ZQ collectibles, score/combo.
- Arena: movement, aim/fire, AI opponent, shield/HP, timer, win/loss.
- Empire: 3x3 city plots, Factory/Habitat/Solar, production, energy, population, reputation, upgrades and local persistence.

It also adds bounded host integration docs, local game-result evidence types and unit tests around the non-secret bridge contract.

This is a games-runtime candidate, not a claim of full legacy Wallet/Social source recovery.
