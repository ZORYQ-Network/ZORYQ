# ZORYQ Games 0.4 — Rush Premium Visual Upgrade

This iteration upgrades the native Android Canvas implementation of ZORYQ Rush without adding Unity, Unreal, Godot or another external game engine.

## Added
- dedicated premium Rush renderer
- richer layered neon city and procedural skyline
- more detailed original humanoid runner with animated limbs
- dynamic camera impact feedback
- ZQ energy shard visual redesign
- new drone obstacle type
- improved obstacle readability and glow treatment
- premium HUD card and Overdrive meter
- ZORYQ Overdrive mode with speed/visual feedback
- near-miss feedback and combo progression
- upgraded particle bursts and trail effects
- retained swipe left/right, jump and slide controls

## Evidence boundary
A successful CI build proves the source compiles and produces Android artifacts. It does not by itself prove installation, launch, frame rate or playability on every real device. Those require device-level validation.
