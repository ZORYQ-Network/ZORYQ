# ZORYQ OBEP External Task Challenge v1

This challenge is the first intentionally useful, deterministic task prepared for an external OBEP executor/verifier experiment.

It is **not** evidence of external demand until a genuinely independent participant executes or verifies it.

## Goal

Given `records.json`, produce a deterministic normalized summary containing:

- SHA-256 digest of the canonical sorted input;
- total record count;
- active record count;
- sum of `amount` across active records;
- per-category `amount` totals across active records;
- SHA-256 hash of the canonical output.

## Determinism rules

1. Parse input as a JSON array.
2. Validate `id`, `category`, integer `amount`, and boolean `active`.
3. Sort records lexicographically by `id`.
4. Canonicalize objects by lexicographically sorting object keys recursively.
5. Hash UTF-8 canonical JSON with SHA-256.
6. Aggregate only records where `active === true`.
7. Sort `categoryTotals` keys lexicographically.
8. Output exactly the JSON object generated by `compute-task.mjs`.

No network access, AI model, API, database, or ZORYQ frontend is required to compute the answer.

## Executor path

```bash
cd zoryq-developer/obep
node external-task/compute-task.mjs external-task/records.json > external-task/result.json
```

## Independent verifier path

```bash
node external-task/verify-task.mjs external-task/records.json external-task/result.json
```

A valid verifier result prints JSON with `verified: true` plus the `inputDigest` and `outputHash`.

## OBEP settlement experiment

For the external economic proof, the executor's exact result becomes the OBEP execution output. The independent verifier recomputes the result. Only an accepted result may proceed to settlement. The ZORYQ Testnet settlement must bind:

`intentId + outcomeId + outputHash`

in the onchain evidence commitment, after which the public Proof Pack must be independently verifiable.

## Security / claim boundary

- No private key is required merely to compute or verify the task.
- Do not send seed phrases or private keys to anyone.
- Participation in the task is separate from any future testnet wallet/settlement step.
- This deterministic challenge proves objective execution/verifiability, not economic demand or AI quality.
