## One-line company description

ZORYQ is an agent-native EVM blockchain testnet that turns developer and AI-agent actions into verifiable on-chain products, project identity and builder intelligence.

## Short pitch

AI agents are becoming capable of taking state-changing actions, but blockchain developer workflows are still fragmented across network configuration, funding, contract calls, safety checks, verification, project identity and usage evidence. ZORYQ is building an EVM-compatible chain and developer layer that makes this path machine-readable and verifiable: Wallet → Faucet → Build → Simulate → Confirm → Broadcast → Explorer → Project Registry → Intelligence → Reputation.
