# KYVO Mobile

Aplicativo mobile KYVO para Android/iOS.

## Núcleo do produto
- KYVO Vault: wallet própria/self-custody (provider seguro a integrar antes de mainnet)
- Swap e cross-chain com espaço transparente para KYVO Fee
- SocialFi com Spotify
- XP, quests, streak, referrals e futuro Airdrop — Coming Soon
- Multi-chain
- Internacionalização automática + troca manual de idioma/região

## Idiomas iniciais
Automático/Sistema, Português, English, Español, Français, Deutsch, Italiano, Türkçe, Русский, 日本語, 한국어 e 简体中文.

## APK pelo GitHub
O workflow `Build KYVO Android APK` extrai `kyvo-source.zip`, valida o projeto, executa Expo Prebuild + Gradle e publica um APK de teste em **Actions → Artifacts**.

> O APK atual é de desenvolvimento/teste. Wallet com dinheiro real, swap mainnet e taxas reais só devem ser habilitados após configuração dos providers, credenciais e revisão de segurança.
