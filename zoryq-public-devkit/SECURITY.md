# Security

ZORYQ Developer Kit is intended for an experimental testnet.

## Never share

- seed phrases;
- private keys;
- production credentials;
- privileged RPC/admin secrets.

## Report privately

If you find a vulnerability that could expose wallet secrets, privileged infrastructure access, unsafe transaction construction, replay weaknesses or unauthorized protocol control, do not publish an exploit path first. Contact the project privately through the repository security-reporting channel when the public repository is live.

## Scope priorities

High-priority areas include:

- wallet signing flows;
- transaction target/value confusion;
- RPC/admin namespace separation;
- Project Registry ownership/identity;
- DEX/Lending contract interactions;
- agent-generated actions;
- dependency/supply-chain risks.

## Current maturity

The public ZORYQ testnet is centralized and experimental. The protocol suite is not represented as audited production finance. ZQ and zUSD have no monetary value.
