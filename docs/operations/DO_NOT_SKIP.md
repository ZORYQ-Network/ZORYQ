# Non-negotiable release rules

1. Never enable real-money execution from preview-only safety logic.
2. Never store private keys or seed phrases in GitHub, Supabase tables, analytics or logs.
3. Never hide KYVO fees inside an exchange rate.
4. Never promise a token or airdrop allocation from XP.
5. Never launch a new chain/provider without a disable path.
6. Never treat a successful APK build as a security audit.
