# ZORYQ — ETHOnline 2026 Continuity Track

## Positioning
ZORYQ is an existing EVM-compatible public testnet with a non-custodial wallet surface, faucet, explorer, quests, leaderboard, node/operator surface and on-chain activity tracking. The ETHOnline submission must clearly distinguish pre-existing ZORYQ work from the new feature built during the event.

## Recommended Continuity build
**ZORYQ Identity + Live Data Layer**

Add a load-bearing integration that gives ZORYQ users and builders human-readable identity and live on-chain intelligence without pretending ZORYQ itself was created during ETHOnline.

Preferred path:
1. Integrate The Graph as a live data source for ZORYQ-related EVM activity or a supported cross-chain feature where eligible.
2. Expose the feature in the wallet / explorer / quests UI.
3. Document exactly what existed before ETHOnline and what was added during the event.
4. Keep the project repository used for judging public.
5. Record a 2–4 minute working demo.
6. Include an architecture diagram and reproducible setup instructions.
