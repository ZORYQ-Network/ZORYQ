# ZORYQ — Outlier Ventures Post Web Base Camp 2026

## One-line description
ZORYQ is an EVM-compatible blockchain testnet and developer ecosystem designed to make on-chain participation, experimentation and network contribution accessible through a unified wallet, faucet, explorer, quests and node/validator experience.

## Stage
Pre-seed / public testnet.

## What is already working
- Public EVM JSON-RPC endpoint
- Chain ID 5919065
- Native test asset ZQ
- Public faucet/onboarding flow
- Explorer
- Wallet-oriented network metadata
- Solidity / ERC-20 / ERC-721 compatibility
- On-chain quest verification for selected actions
- Leaderboard / Genesis participation layer
- Node/operator interface

## Problem
Launching and growing a new blockchain is fragmented for users and developers: network configuration, faucets, tooling, identity, quests, test activity and infrastructure participation are typically split across multiple products. This creates onboarding friction and weak early network effects.

## Solution
ZORYQ combines the chain and the onboarding loop. A new participant can discover the network, add it to an EVM wallet, receive test ZQ, perform on-chain actions, deploy contracts, participate in quests and progress toward deeper network roles from one ecosystem.

## Why now
EVM developer tooling is mature, while new networks still compete on distribution, onboarding quality, developer experience and community participation. ZORYQ is focusing its testnet around measurable real activity rather than vanity metrics.

## Differentiation
- Network + wallet + onboarding + quests + explorer in one experience
- EVM compatibility lowers developer switching costs
- Participation system tied to verifiable on-chain actions
- Explicit path from user to builder to node/operator participant
- No claim that testnet ZQ has monetary value
