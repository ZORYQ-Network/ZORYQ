# ZORYQ Design Partner / Pilot Program

ZORYQ is opening a small evidence-first pilot program for external teams that want to test verifiable agent workflows on an experimental public EVM testnet.

## Best-fit pilot

The strongest current product direction is **Autonomous Company / Agent Commerce**:

`goal + bounded budget -> company -> agents -> tasks/hire -> authorization -> onchain action/payment -> verified receipt -> accounting -> Proof Pack`

A pilot should focus on one narrow real workflow, not a broad transformation project.

## Good pilot candidates

- AI-agent teams that need bounded spending/permissions;
- services that want machine-readable proof that an agent completed a task;
- marketplaces for agents/services;
- research or operations teams that need auditable agent actions;
- developer platforms that need verifiable agent payment/receipt infrastructure.

## What ZORYQ provides during a pilot

Subject to the current experimental stage:

- testnet infrastructure and public RPC;
- technical onboarding;
- a narrowly scoped integration plan;
- evidence schema / Proof Pack design;
- public or private reproduction checklist depending on the workflow;
- issue-based tracking for non-sensitive technical blockers.

## What a partner provides

- one concrete workflow/problem;
- one technical or product owner;
- measurable success criteria;
- realistic test data or a safe test scenario;
- feedback on product friction;
- permission before any public use of the partner name or results.

## Pilot outcomes

A pilot is successful only when the agreed success criteria are met with reproducible evidence. Depending on scope, this can include:

- successful external deployment;
- wallet-authorized action;
- verified onchain receipt;
- bounded permission enforcement;
- reconciled accounting;
- exported Proof Pack;
- repeated use on a later date.

## Commercial status

An exploratory technical test is not a commercial partnership.

A **paid pilot** counts as commercial traction only after terms/scope are agreed and payment is actually received. A **formal design-partner pilot** counts only after scope, owner and test period are recorded.

ZORYQ should not report casual conversations as customers, partnerships or revenue.

Open a GitHub issue using the **Design partner / pilot interest** template.

For sensitive commercial details, use a private communication channel after initial qualification.
