# ZORYQ Unified Platform

This page is the shortest source-of-truth index for the consolidated platform.

## One platform, five layers

1. **Chain** — EVM testnet, RPC, state, nodes, protocol evidence.
2. **Identity + Wallet** — self-custody, recovery, signing, sessions and application identity.
3. **Autonomous Network** — bounded agents, tasks, proof and accountable economic activity.
4. **Applications** — Social, Games, AI App Factory and future products.
5. **Economy** — user funds, treasury, fees, agent/application commerce and settlement boundaries.
