# KYVO Fee Policy

- Default preview target: 15 bps (0.15%).
- Fee changes must be configuration-driven and auditable.
- User review shows KYVO fee separately from network/provider costs.
- No fee may be activated without a configured partner integrator and public treasury destination.
- Treasury signing material is never stored in mobile code or GitHub.
- Promotional fee discounts must not manipulate or misrepresent final execution price.
