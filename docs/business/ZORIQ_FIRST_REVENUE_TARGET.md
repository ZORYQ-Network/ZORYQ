# ZORIQ First Revenue Target

The first milestone is deliberately concrete:

**A real user completes an eligible ZORIQ-routed transaction, sees the ZORIQ fee before authorization, the transaction settles successfully, the fee reaches the correct official treasury, and the backend reconciles the event without any custody of the user's keys.**

The alternative first milestone is the first valid ZORIQ Pro store subscription with entitlement/restore/refund handling working correctly.

Neither milestone is considered achieved from a UI preview, test fixture or simulated payment.
