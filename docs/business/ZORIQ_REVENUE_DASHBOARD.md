# ZORIQ Revenue Dashboard

Admin/business dashboard should expose:
- routed volume by chain/provider;
- gross ZORIQ fees;
- partner/provider share;
- net reconciled revenue;
- revenue by treasury/network namespace;
- pending/unreconciled events;
- Pro MRR, subscribers, churn and refunds;
- B2B usage/revenue when enabled;
- fee-policy version distribution;
- alerts for reconciliation exceptions.

Dashboard data is reporting metadata. It never exposes wallet private keys/seeds.
