# KYVO Platform Overview

KYVO is designed as both a consumer mobile app and a future platform layer.

## Consumer app
- Vault
- Route/Swap
- SocialFi
- Spotify presence
- XP/Rewards
- ONE intents
- Guard safety
- Pro

## Platform products
- KYVO Guard API
- KYVO Intent API
- KYVO Route API
- KYVO ID resolver

## Strategic objective
Do not compete only on wallet UI. Build reusable safety, intent and identity capabilities that can later be integrated by other crypto products.
