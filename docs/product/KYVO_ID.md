# KYVO ID

KYVO ID é a camada de identidade humana da wallet.

Exemplo: `@michael`

Um KYVO ID pode apontar para múltiplos endereços verificados e preferências de recebimento por rede/ativo.

## Dados mínimos
- username único;
- endereços verificados;
- rede preferida por categoria de ativo;
- controles de privacidade;
- histórico de alterações sensíveis;
- proteção anti-impersonação.

## Regra de segurança
Nunca redirecionar fundos silenciosamente para um endereço não verificado. Alteração de mapping exige autenticação forte e audit log.
