# ZORIQ Positioning

## Promise
**Crypto without complexity.**

ZORIQ should feel like one product even when the user owns assets across multiple networks.

## Core stack
- **ZORIQ Vault** — self-custody wallet surface;
- **ZORIQ Route** — swaps/cross-chain execution and transparent fees;
- **ZORIQ ONE** — intent planning;
- **ZORIQ Guard** — safety analysis before authorization;
- **ZORIQ ID** — human-readable multi-network identity;
- **ZORIQ Social** — distribution/community;
- **ZORIQ XP** — useful-activity progression;
- **ZORIQ Pro** — paid power-user layer;
- **ZORIQ Business** — future APIs/SDKs;
- **ZORIQ Network** — future execution layer only after traction.

## Product rule
Users should never need to understand a new chain merely to use ZORIQ. Chain selection is an implementation detail unless the user explicitly chooses advanced control.
