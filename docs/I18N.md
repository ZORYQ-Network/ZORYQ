# Internacionalização e Região

## Comportamento padrão
No primeiro uso, ZORYQ detecta locale/região do sistema. `Automático (Sistema)` permanece como default até o usuário escolher override.

## Idiomas iniciais
- Português
- English
- Español
- Français
- Deutsch
- Italiano
- Türkçe
- Русский
- 日本語
- 한국어
- 简体中文

## Configurações
`Profile → Settings → Language & Region` permite:
- idioma;
- região;
- moeda de exibição;
- formato de número/data;
- timezone quando necessário.

## Regras técnicas
- nenhuma string de produto importante hardcoded em tela;
- chaves semânticas estáveis;
- fallback para English;
- pluralização e datas por locale;
- valores crypto não devem perder precisão por formatação;
- traduções financeiras revisadas por humano antes de produção.

## RTL
Arquitetura deve permitir RTL futuramente, mesmo que árabe/hebraico não entrem no primeiro pacote.
