# ZORIQ North-Star Metrics

## Adoption
- monthly active funded wallets;
- activation: installed -> wallet ready -> first useful action;
- 7/30/90-day retained funded users;
- verified ZORIQ IDs;
- successful sends/swaps per active wallet.

## Revenue
- eligible routed volume;
- gross ZORIQ fee;
- partner share;
- net ZORIQ route revenue;
- ZORIQ Pro MRR, conversion and churn;
- B2B MRR / API usage when launched.

## Safety
- Guard analyses;
- high-risk actions warned/blocked by policy;
- transaction failure rate;
- support incidents per 1,000 transactions;
- treasury reconciliation exceptions.

## Product quality
- quote latency;
- route success rate;
- crash-free sessions;
- wallet creation/recovery success;
- locale coverage and translation errors.

## Rule
Downloads and social impressions are supporting metrics. The core business is measured by **retained funded users + safe successful activity + reconciled revenue**.
