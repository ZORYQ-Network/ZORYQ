# KYVO Roadmap

## Fase 0 — Foundation
- marca KYVO;
- mobile shell;
- i18n;
- GitHub CI APK;
- documentação e segurança baseline.

## Fase 1 — Closed Alpha
- auth;
- KYVO Vault em ambiente de teste;
- testnet send/receive;
- Home portfolio;
- SocialFi básico;
- XP local + backend ledger inicial;
- Spotify PKCE.

## Fase 2 — Testnet Beta
- multi-chain adapters;
- swap quotes testnet/simulação;
- quests/streaks/referrals;
- anti-sybil;
- crash/analytics privacy-safe;
- security assessment.

## Fase 3 — Limited Mainnet
- wallet production provider;
- mainnet wallet/send;
- swap com limites e providers aprovados;
- fee KYVO transparente;
- treasury reconciliation;
- incident monitoring.

## Fase 4 — Public Launch
- store release;
- broader networks;
- creator/social discovery;
- WalletConnect;
- premium/referral economics.

## Fase 5 — Ecosystem
- trading adapters;
- NFTs/collectibles;
- SDK/partners;
- comunidades;
- avaliação formal de token.

## Fase 6 — Token somente se aprovado
- legal/tokenomics/audit;
- snapshot;
- claim infrastructure;
- governance progressiva.

Datas só devem ser anunciadas quando houver capacidade real de entrega.
