# ZORYQ Wallet 1.1.0

Release candidate scope:
- multichain EVM wallet core;
- built-in major EVM mainnets plus validated custom EVM networks;
- ERC-20 watchlist and balances;
- native/ERC-20 transfer preflight and gas estimation;
- SecureStore-backed self-custody with device authentication when available;
- transparent revenue policy: 0 bps wallet fee on transfers, 25 bps target integrator fee on supported swaps;
- swap revenue remains fail-closed until production Treasury and secure backend are configured.

Release status: PRE_MAINNET_WALLET until external audit, signed-release custody, real-device security tests, production Treasury custody and store/privacy controls are complete.
